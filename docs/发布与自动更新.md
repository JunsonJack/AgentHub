# AgentHub 发布与自动更新

> 自用版可手动安装 NSIS 包；开源分发建议走 GitHub Releases + Tauri Updater。

## 一、首次准备签名密钥（只需一次）

```bash
# 在项目根目录执行（Windows PowerShell）
npx tauri signer generate -w .tauri/agenthub.key
```

会生成：
- 私钥文件（如 `.tauri/agenthub.key`）—— **只留在本机 / CI Secret，不要提交**
- 公钥字符串（`dW50cnVzdGVk...`）—— 写入 `src-tauri/tauri.conf.json`：

```json
"plugins": {
  "updater": {
    "endpoints": [
      "https://github.com/JunsonJack/AgentHub/releases/latest/download/latest.json"
    ],
    "pubkey": "<粘贴公钥>"
  }
}
```

把私钥路径与密码写入环境变量后再打包：

```powershell
$env:TAURI_SIGNING_PRIVATE_KEY = "path\to\agenthub.key"
$env:TAURI_SIGNING_PRIVATE_KEY_PASSWORD = ""   # 生成时若设了密码则填入
npm run tauri build
```

## 二、构建产物

`npm run tauri build` 成功后，更新相关产物在：

```
target/release/bundle/
  nsis/AgentHub_<ver>_x64-setup.exe
  nsis/AgentHub_<ver>_x64-setup.exe.zip
  nsis/AgentHub_<ver>_x64-setup.exe.zip.sig   # 签名
```

以及更新元数据（若 CLI 版本支持会一并生成；否则按下文手写）`latest.json`。

## 三、`latest.json` 形态（Tauri 2）

```json
{
  "version": "0.1.1",
  "notes": "更新说明（会显示在设置页）",
  "pub_date": "2026-09-20T12:00:00Z",
  "platforms": {
    "windows-x86_64": {
      "signature": "<.sig 文件的全部内容>",
      "url": "https://github.com/JunsonJack/AgentHub/releases/download/v0.1.1/AgentHub_0.1.1_x64-setup.exe.zip"
    }
  }
}
```

把 `latest.json`、`*.exe.zip`、`*.exe.zip.sig` 一并上传到 GitHub Release。
更新端点固定为：

`https://github.com/JunsonJack/AgentHub/releases/latest/download/latest.json`

## 四、版本号同步

发布前把下列三处改成同一版本：

| 文件 | 字段 |
|---|---|
| `package.json` | `version` |
| `Cargo.toml`（workspace） | `package.version` |
| `src-tauri/tauri.conf.json` | `version` |

## 五、应用内行为

- 设置页 →「关于与更新」→「检查更新」
- 有新版本时展示 notes，点「下载并安装」→ 校验签名 → 安装 → 自动重启
- 未配置 pubkey 或 endpoint 不可达时，会给出明确错误，不影响其它功能

## 六、自用（无签名）场景

未生成密钥前，应用内「检查更新」会失败。可继续手动安装：
从 Release 或本机 `target/release/bundle/nsis/` 双击 setup.exe。
代码与 UI 已就绪，补上 pubkey 后无需改前端。
